# app/Config

Contiene configuración centralizada del proyecto.

Archivos principales:

- `database.php`: conexión PDO a PostgreSQL.
- `google.php`: configuración de Google Login.
- `mail.php`: configuración SMTP/correo.
- `company.php`: datos públicos de empresa.

En Fase 3 las rutas antiguas de la raíz siguen existiendo como adaptadores.
