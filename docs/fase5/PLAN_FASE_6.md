# Plan Fase 6: mover SQL, migraciones, funciones y triggers

## Objetivo

Ordenar todos los archivos SQL.

## Carpetas objetivo

```text
database/schema
database/migrations
database/hotfixes
database/triggers
database/functions
database/seeds
database/queries
```

## Qué se hará

1. Clasificar migraciones.
2. Clasificar hotfixes.
3. Separar triggers.
4. Separar funciones SQL.
5. Crear índice de ejecución recomendado.
6. Documentar qué SQL ya fue aplicado y cuál es opcional.

## Regla

No ejecutar SQL automáticamente desde PHP.
Solo ordenar archivos y documentar.
