# Servicios creados en Fase 4

## PricingService

```text
app/Services/Catalogo/PricingService.php
```

Responsabilidad:

```text
Calcular precio con IVA, descuentos de producto, descuentos por volumen y descuento de membresía.
```

## SerialNumberService

```text
app/Services/Inventario/SerialNumberService.php
```

Responsabilidad:

```text
Generar SKU, generar número de serie y validar series devueltas.
```

## SupplierCapacityService

```text
app/Services/Proveedor/SupplierCapacityService.php
```

Responsabilidad:

```text
Normalizar rangos de proveedor, calcular descuento por cantidad, estimar días de producción y transporte.
```

## BusinessRulesReference

```text
app/Services/ReglasNegocio/BusinessRulesReference.php
```

Responsabilidad:

```text
Mantener un mapa explicativo de reglas principales del negocio.
```
