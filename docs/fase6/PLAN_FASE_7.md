# Plan Fase 7: adaptadores para rutas antiguas

## Objetivo

Revisar todas las rutas antiguas del proyecto y confirmar que sigan funcionando aunque la estructura interna ya esté separada.

## Acciones

1. Revisar controladores de raíz.
2. Verificar adaptadores PHP creados en fases anteriores.
3. Verificar adaptadores SQL de Fase 6.
4. Documentar rutas antiguas y nueva ubicación interna.
5. Corregir cualquier enlace roto.

## Regla

No eliminar todavía archivos antiguos. Primero se confirma compatibilidad.
